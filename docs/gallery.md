# Seven photos, seven keepsakes · 七张照片，七枚回忆

[English README](../README.md) · [中文说明](../README.zh-CN.md)

Every pair below is a real source photograph and its generated concept image. All seven outputs were generated and visually inspected in Codex on 2026-09-19. Each photo was processed separately with the same painted-resin and warm-background direction.

以下均为真实原照片与生成效果图，七张成品已逐张查看。图片按各自的景物轮廓设计，统一彩绘树脂和暖白背景；是艺术化转绘，不是精确复刻或可打印模型。

Published images are resized copies. GPS coordinates, capture dates, device identifiers, EXIF, XMP, IPTC, comments, and embedded thumbnails have been removed. The original source files are not included in this repository.

公开图片均为缩小后的副本，已清除 GPS 坐标、拍摄时间、设备标识、EXIF、XMP、IPTC、注释和内嵌缩略图；原始文件不进入本仓库。

## About these images · 关于示例图片

Source photographs were supplied by the project creator. Display copies are resized for the README and have camera metadata removed; no original photo was redrawn to fabricate a comparison. Original files and internal test records are not part of this repository.

原照片由项目作者提供。展示副本仅做格式、体积优化与拍摄元数据移除；没有重画一张“原图”来伪造效果对照。结果会受参考图质量、宿主图像能力与模型变化影响。

The trial covered landscapes, skylines, architecture, pets within a scene, and an everyday street. Lettering, transparent output, later local edits, and other hosts were not evaluated in that trial.

本次样本包含风景、城市天际线、建筑、场景中的宠物及普通街景；未覆盖铭牌文字、透明底、后续局部编辑或其他宿主。
